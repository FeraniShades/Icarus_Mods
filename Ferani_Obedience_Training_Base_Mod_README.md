Base mod: required for Ferani's Obedience Training-collection.

A base mod for all the other pet mods to comfortably sit on top of... Who would wanna sit on the ground?

This is a base mod for Ferani's Obedience Training. It works by having this base-mod add a hooking modifier to an essential mount/tame file, which all the other mods need to do their thing. 

All mods within this collection MUST have this mod to function unless stated otherwise, but you don't need all the other mods - only pick the ones you like.

FAQ:
Do I need the entire Obedience Training-collection for it to work?
No, you only need this base mod for any other Obedience Training mod to work, unless stated otherwise. So you're free to only get a single mod or all of them at once.

Do I need to download multiple base files for each pet mod?
No, you only need to add this base mod once, and then any of the pet mods within the collection will work with it.

Do I need this base file for all the other Ferani mods to work?
No, you only need this base mod for the Obedience Training-collection (all the mods with the word "Paws" in them). All of my other mods are stand-alone and work on their own.

Is this mod compatible with other mount-mods?
Yes, any other mounts and tames should work just fine with this mod! I personally recommend JimK's Bear Mount and Workshop Pets or my own Blueback/Redbacks.

Used files:
D_TamedCreatureModifiers
D_ModifierStates
D_Stats
D_GrantedAuras
BT_Mount

If you have any other mods that affect BT_Mount, they might conflict, so make sure to check.

Feel free to message me if you come across any bugs that need patching.

Installation:

WITH ICARUS MOD MANAGER by JIMK72 (RECOMMENDED):
Download the EXMODZ-file
Open your Mod Manager
On the right side, choose "Import EXMODZ File"
Choose the EXMODZ-file you just downloaded (extract it from ZIP), and it will show up on the list on the left
Add it to your list of "Mods to Install" by double-clicking on the mod name
Merge it by itself or with other mods (there may be conflicts, so keep an eye on what is being merged)
Play!
